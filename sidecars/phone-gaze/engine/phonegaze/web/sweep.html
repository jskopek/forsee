Sweep

Replays your recorded setups through thousands of setting combinations with nobody at the computer, and ranks them on validation dots that no fit ever saw. Then it says why each setup's error is what it is. It runs in the background: you can close or reload this page. It has only been tried on simulated recordings so far.

From the terminal

python -m phonegaze sweep RUN_ID                 # a collection run (collect-runs/RUN_ID.json)
python -m phonegaze sweep ~/.phonegaze/recordings/SOME_RECORDING --minutes 20
python -m phonegaze diagnose RUN_ID              # only the "why is the error what it is" part

How to read the results: docs/SWEEP.md.
