Diagnostics bundle

Writes one folder on this Mac (in ~/.phonegaze/diagnostics) with the log, settings, calibration scores, the checklist, stream statistics, timings and the last few seconds of measurements (numbers only), plus a short summary to paste into a chat. Nothing is uploaded: the folder stays on this Mac until you send it to someone. 


        

          From a terminal: python -m phonegaze doctor and
          python -m phonegaze bundle [--images] (in sidecars/phone-gaze/engine, with
          .venv/bin/python).
