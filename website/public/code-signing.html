Code signing and privacy

Code signing policy

Free code signing for Windows is provided by SignPath.io, with a certificate by the SignPath Foundation. The macOS app is signed with the project's Apple Developer ID and notarised by Apple.

Only builds made by the project's public release workflow from the source code on GitHub are signed. Every signed release is listed on the releases page.

Team roles

  • Committers and reviewers: project members
  • Approvers: jskopek

Privacy

Forsee works on your computer. What you type, what you say and your settings stay on your computer and are never sent anywhere.

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it, with one exception: to keep itself up to date, Forsee asks GitHub (github.com) a few times a day whether a new version is available, and downloads it from there. That request contains only the information any download does (such as your IP address and the app version), and is covered by GitHub's privacy statement.
