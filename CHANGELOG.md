# Changelog

Every release of the Forsee app. The Release workflow publishes a version
only when it has an entry here, and uses the entry as the release notes.
Write for the people who use Forsee, not for developers.

## 0.2.0

The first version you can install on a Mac or a Windows PC.

- Forsee for Mac and Windows, with a normal installer: drag to Applications on
  a Mac, double-click on Windows. On Mac, this version needs Apple silicon
  (M1 or newer).
- Keeps itself up to date. New versions download in the background and
  install the next time Forsee is closed; it never restarts while you are
  talking.
- Speech works from the start, without anyone needing to click first.
- The screen stays awake while Forsee is open.
- Type by dwell with an eye tracker or head pointer, or by touch; word
  predictions that learn your words; quick replies (Yes, No, Help, ...);
  Faster and Slower; Pause; several keyboard layouts including large keys;
  voice and speaking-rate settings.
